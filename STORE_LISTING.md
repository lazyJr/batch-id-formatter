# Chrome Web Store listing / Chrome 网上应用店文案

## English

**Name:** Batch ID Formatter

**Short description:** Format lists of IDs separated by spaces or punctuation, choose quotes, and copy the result.

**Detailed description:**

Turn pasted IDs into a clean, comma-separated list with one item per line. Choose double quotes, single quotes, or no quotes, then copy the result in one click.

The extension accepts spaces, new lines, commas, semicolons, Chinese punctuation, and quotes as separators. When these separators are present, it keeps every ID intact. It can also split adjacent letter-and-digit IDs when no separators are present. For adjacent numeric IDs, you can set the number of digits per ID.

Everything runs locally in the popup. No account, network access, or browser permissions are required.

**Single purpose:** Format pasted IDs into a copyable list.

**Privacy policy URL:** https://github.com/lazyJr/batch-id-formatter/blob/main/PRIVACY.md

## 简体中文

**名称：** 批量编号格式化

**简短描述：** 整理空格或标点分隔的编号，选择引号格式并一键复制结果。

**详细描述：**

将粘贴的编号整理为每行一个、逗号分隔的列表。可选双引号、单引号或无引号，一键复制结果。

支持空格、换行、逗号、分号、中文标点及引号等分隔符。有明确分隔符时，编号内部内容会保持原样；完全没有分隔符时，可拆分相连的「字母 + 数字」编号。纯数字编号相连时，可以指定每个编号的位数。

所有处理均在弹窗本地完成，无需账号、联网或浏览器权限。

**单一用途：** 将粘贴的编号整理为可复制的列表。

**隐私政策网址：** https://github.com/lazyJr/batch-id-formatter/blob/main/PRIVACY.md
