# 批量编号格式化（Batch ID Formatter）

一个无需联网的 Chrome 扩展：把粘贴的编号整理成每行一个、以逗号分隔的列表，并选择双引号、单引号或无引号。默认使用双引号。

## 安装

1. 下载或克隆本仓库。
2. 打开 Chrome 的 `chrome://extensions`，启用「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的项目文件夹。
4. 点击工具栏中的「编号格式化」图标，粘贴内容并复制结果。

## 识别规则

- 输入包含空格、换行、英文或中文逗号、顿号、分号、引号时，只按这些符号拆分；连续分隔符不会产生空项。编号内部保持原样。例如 `VIP123;;;;SSS456; AB12CD34` 会得到三个完整编号。
- 整段输入完全没有上述分隔符时，才尝试拆开连续的「字母 + 数字」片段。例如 `AB123CD456` → `AB123`、`CD456`。
- 纯数字粘连无法自动推断边界，可在页面填写每个编号的位数。末尾不足该位数的数字仍会保留为一项。
- 顺序与重复项保持不变，不校验编号的业务含义。

## 示例

输入：

```text
VIP123;;;;SSS456; AB12CD34
```

默认输出：

```text
"VIP123",
"SSS456",
"AB12CD34"
```

## 开发与隐私

项目使用原生 HTML、CSS 和 JavaScript，无构建步骤或外部依赖。运行 `node --test tests/formatter.test.js` 可验证主要识别规则。扩展不申请浏览器权限；粘贴内容仅在弹窗本地处理，不上传到服务器，也不写入本地存储。
